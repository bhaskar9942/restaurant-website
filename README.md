# YPD Foods – Responsive Restaurant Website

A single-page, responsive restaurant website built to demonstrate front-end development skills using HTML5, CSS3 and JavaScript.

## Project Overview

YPD Foods is a front-end demonstration website that presents a restaurant-style menu and contact section through a clean, interactive user interface. The project focuses on page structure, visual styling, responsive layouts and client-side interactions.

> **Note:** This is a front-end demonstration project. It does not include a backend, database, payment processing or a live food-ordering system.

## Features

- Responsive navigation for desktop and mobile screens
- Mobile hamburger menu with accessible controls
- Navigation links that scroll to page sections
- Navigation bar styling that changes while scrolling
- Food menu sections for Biryani, Starters, Drinks, Desserts and Ice Cream
- Food cards with descriptions and sample prices
- Restaurant contact information section
- Responsive layout and image loading optimizations

## Technologies Used

- **HTML5** – page structure and semantic elements
- **CSS3** – styling, layouts, responsiveness and visual effects
- **JavaScript** – interactive navigation and scroll behavior

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Explore the website and test the navigation on desktop and mobile screen sizes.
