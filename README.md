# YPD Foods – Responsive Restaurant Website

A responsive restaurant website built to showcase food categories, menu items and restaurant contact information through a clean, interactive interface.

## Project Overview

YPD Foods is a single-page restaurant website designed to provide visitors with an engaging way to explore a restaurant menu and find contact information.

## Features

- Responsive navigation bar
- Mobile-friendly hamburger menu
- Navigation bar styling changes on scroll
- Interactive food menu sections
- Food categories including Biryani, Starters, Drinks, Desserts and Ice Cream
- Food cards with descriptions and prices
- Navigation between page sections
- Restaurant contact section

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

```text
restaurant-website/
├── index.html
└── README.md
```

The HTML, CSS and JavaScript are currently contained in a single HTML file.

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Explore the restaurant website.
